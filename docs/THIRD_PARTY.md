The game code, shapes, map, names and UI were created for this project. There are no imported commercial-game visuals, music or assets. The UI uses Godot's fallback font supplied by the engine. Godot and its embedded fonts/libraries have separate notices.

Godot Engine is MIT licensed. Redistribution must retain the relevant notices. Read [Godot's official license guidance](https://docs.godotengine.org/en/stable/about/complying_with_licenses.html), the matching [engine license](https://github.com/godotengine/godot/blob/4.6-stable/LICENSE.txt) and [bundled third-party copyright/license file](https://github.com/godotengine/godot/blob/4.6-stable/COPYRIGHT.txt).

The Windows package includes copies of these engine notices in `licenses/`. Include them in each future binary distribution. Android's app listing/about/legal page should expose engine attribution and required third-party notices before public release. This MVP has no finished in-app legal screen; add one before store submission. Docker-installed Debian packages and Caddy also retain their own licenses.
